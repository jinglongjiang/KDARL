# 路线B修订执行方案

## 目标与边界

本轮仅做跨检查点现象复核、来源审计与先例核查。不是KDA性能优化算法，不是Delta Rule创新，也不是导航收益验证。零训练，不改原项目、reward、filter、动作、权重；不使用4090，不碰92000–92499留出块。

原protocol.json与frozen-manifest.json保留不动。修订以protocol-amendment-v2.json为准；此次修订发生于原P1自身轨迹采集完成之后，所有已完成记录保留，不伪装成事前注册。

## P1：三种间距严格分开

| 指标 | 定义 | 允许解读 |
|---|---|---|
| Value Gap | 候选后继V前两名之差 | 网络后继价值区分度；不等于Q Action Gap |
| Raw Gap | 未过滤r+0.99V前两名之差 | 当前单步前瞻近似的评分区分度 |
| Decision Gap | 原filter允许集合中，reward、risk及既有索引0扣分后的完整评分前两名之差 | 当前最终动作评分的区分度；不是实际Q_pi或最优Q |

完整分数为raw−0.8×max(0,0.2−predicted_clearance)−0.001×I[index=0]。
至少两个预测安全候选时定义正常Decision Gap；仅一个时记null；全部不安全时单列fallback gap。不得把-1e9掩码或fallback混进正常间距分布。

同时保留V前五名的速度、速度展度、预测净距、实际一步净距，及最终选中索引、命令、速度、预测/实际净距和V名次。速度向量差与速度幅值差分开记录。

全部候选共享真实当前状态锚定的TTC5集合及alpha=0.3平滑合同。实际行人下一帧用于候选几何的前提是robot.visible=False，必须断言；若该条件不成立则不能将沿已执行轨迹的下一帧复用于其他候选。

步级指标是描述量。区间按case ID聚类重采样，保留同case六格和全部时间步；只有20个case簇，不把数万步或11份权重当独立样本。

## 结论约束

- 11份相似最多支持“该现象跨已测配置重复”，不能证明稀疏Reward、MC目标或KDA架构造成它。
- 一步净距、速度不同不代表长期动作价值不同；小间距不证明排错、有害振荡或扩大间距有收益。
- 同一冻结权重的配对干预仅说明该权重条件下的效果，不能自动推广到其他训练seed。
- 两seed绝对差称为“已观测跨训练Seed波动范围”，不是训练方差、噪声地板或显著性阈值。
- PBRS最优策略不变不排除有限IL+MC训练收益；只改reward而保留旧V也可能改变当前argmax。
- 方向①Reward研究不因本审计停止；本轮也不自动启动未经定义的Reward训练。方向②Delta创新单独立项，不拿P1替代机制或收益证据。
