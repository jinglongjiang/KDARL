# wu-01 必要查询对照（新增授权后、任何对照训练前登记）

未验证：风险选样有效或省查询。原 X1/X2 训练代码、λ 选择及已启动的 X2 不改动。

两条控制复用 XPilot 的网络执行动作、MC 回报、AdamW 状态、空 replay、蒸馏温度 .1、batch 4、FIFO 2048、λ=.1、更新节奏及首次 correctness 审计（28 实际步）。训练起点和 seed 与 X1/R0 相同；各自预算 402000 真实环境步，未完成轨迹不写 MC 标签。正式对照默认均在 4090、X1 与其评测完成后依次执行，以保持训练设备一致；每条开始前 loadavg1<4、MemAvailable≥2 GiB。允许的本地 3060 备用资源本次不抢占正在运行的 X2。

X1-rand：每个实际采集步使用独立 random.Random(20261017) 做 Bernoulli(q)，不消费学习或 MPPI RNG。q = X1 最终 teacher_calls / X1 counts.train，裁剪到 [0,1]，X1 完成后一次冻结，不看测试结果、不事后补齐或删改查询。目标为期望查询总量匹配；实际误差同时报告，预登记相对偏差≤1%视为查询预算近似匹配，超出则选择归因未验证，不重扫 q。原 X1 在到达 cap 后可能额外计算一次未执行的决定，已知至多一次计数差异单列披露，不修改原 X1。

X1-all：每个实际采集步均调用 MPPI，correctness 步不询问，cap 之后不询问。报告真实优化器调用数、有效老师标签数、进入蒸馏 replay 的标签数、蒸馏更新数、老师耗时和训练总墙钟。

老师复用同一冻结 Controller 的动力学、即时/终端代价、256 样本、16 步、离散投影、平滑及硬安全认证；仅查询时刻不同。连续查询保留原 16 步激活块内的 warm-start；未查询时清空计划（如 X1 的 idle）。有查询但没有安全候选也实际调用优化器；认证无效则记录回退且不生成蒸馏标签，规则与 X1 一样不把回退网络动作伪造成有效老师标签。所有实际执行动作仍由网络产生。记录认证成功率，避免把调用次数等同有效监督数量。

实现采用新增 control_core.py、control_train.py、control_check.py、control_queue.py、controls_summary.py；原 core.py/train.py 不改。原查询优化器分支在 control_core.py 只读复用相同原语，冒烟前对安全场景验证与冻结 Controller 强制激活分支的老师动作、诊断和计划逐位一致；另检查全不安全时确有调用但无有效标签。关闭查询时比较原 R0 的动作、MC 经验、每次损失、模型和 AdamW 更新。每条先做本地 2000 实际步冒烟，正式 q 从完成的 X1 获取。

评测采用现有隔离评测源码和同一 410000–410499 区块，两场景各 500、最终权重纯一步前瞻。X1/base/R0 已有回合只读复用，初始世界哈希按 case 对齐，paired bootstrap 10000、seed 20261017、95% percentile。报告两条控制各自对 X1/R0 的 SR/CR/TO 差值，以及效率和计算时间。

裁决：逐场景报告 X1−X1-rand ΔSR≥2pp 且下界>0 为“风险选样有效”；X1−X1-all 下界>−2pp 且 X1 查询更少为“省查询”。20S 是原预注册主场景，20C 单列。未达到门槛写未验证，不把未显著差异说成等效。查询预算未匹配或存在老师实现差异时不声称选择归因。结果决定支持相应命题或不支持，不自动追加调参实验。

队列与报告监督单独新增，等待原任务完成标记；任一训练/评测异常停止新增队列，保留原任务成果。所有启动、完成及排队变更写本目录 PROGRESS.md。完整任务完成标记将区分原始两臂与新增控制。
