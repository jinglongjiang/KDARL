# X2-KF：固定滤波对照（实现及任何新块 KF 评测之前登记）

未验证：滤波或 X2 相对滤波的导航收益。KF 仅用于对照，不进入 X2 训练或我们的方法。

每人一个独立常速线性 KF，状态顺序 [px,py,vx,vy]，dt=.25；F 为位置加 dt×速度、速度保持不变。测量 H=I。噪声 .1 格 R=diag(.1²,.1²,.2²,.2²)，漏检 .2 格测量无噪声，R=0。Q=G diag(a²,a²) Gᵀ，G 的位置行为 .5dt²、速度行为 dt，a=σ_v/dt，σ_v=2σ_p。因此 Q 仅由已知扰动参数和 dt 固定；这是预设的过程近似，**不是已知的 ORCA 真实过程噪声，也未在测试块估计它**。漏检格 σ=0，Q=0；由于每次有效观测是完整精确状态，更新直接 x=z、P=0，等价于零观测噪声 KF 的硬约束极限；漏检之间只做 F 预测。噪声格使用 Joseph 协方差更新以保持数值稳定。

初始化 x=首个可用测量，P=R。每回合重新建 20 个滤波器，按环境稳定人员编号对应，无关联重排，无真值初始化。半径沿用最近一次有效观测，机器人自身状态不滤波。漏检指示由同一扰动采样器提供；该指示是滤波基线额外可用的检测信息，原 R0/X2 网络只收到上次观测，不将该信息优势藏起来。

采样器严格复刻 CC_PERCEPT：RNG=RandomState(case*17+29)，每人先生成位置/速度高斯噪声，然后在存在历史时抽漏检；即便漏检也消耗相同噪声随机数，但丢弃该次测量，滤波器绝不读它。漏检时不对“沿用的旧值”做测量更新。每个物理时刻缓存一次，重复读取不重抽、不重复更新。真实世界、行人动作和奖励不改。

回归先在历史块 311000–311004：base、R0 各 5 个 20S 干净回合，KF 关闭，逐例比较 outcome、步数、场景/动作/选择摘要、return、路径及最小净距与原冻结评测记录。再跑两种扰动、base/R0 的 KF 单例冒烟；不在 410000–410499 上调任何参数。数值检查包含原采样器逐位一致、缺测只预测、R=0 有测量精确重置、Q/R 与设置一致、协方差有限且半正定、真实世界不被修改。

正式不训练，最终冻结 R0/base 权重，20S，噪声 .1、漏检 .2，各 500 例，410000–410499。共 4 格 KF；另补 base 无 KF 的两个扰动格作为同硬件控制（原流水线已有 R0/X2 的无 KF 格，只读复用）。纯一步前瞻，不加 MPPI。按 case 校验真值初始场景并配对 bootstrap 10000、seed=20261017、95% percentile。主要报告 X2−R0+KF、R0+KF−R0；同时列 base+KF、base 无 KF，以及 X2−base+KF、base+KF−base。报告 SR/CR/TO、成功时间/路径、推理成本及滤波 CPU 耗时。
