# Strong Mother F / MPPI

已验证：零训练；每母体每场景 500 个固定配对 case，311000–311499。20 人、50 秒、TTC5、80 动作、alpha=0.3、原安全与风险项。

已验证：2000 个 base 回合逐例复现；4000 个规划回合全部完成。另有 310000–310004 的 60 个冒烟回合，不混入正式 500 例分母。全部阶段退出码为 0，未遗漏或重复 case。

已验证：成功回合的 F 为 GRU 方形 82.67%、GRU 圆形 87.94%、KDA 方形 88.95%、KDA 圆形 94.49%。该规则不是超时独有特征，不能把一次触发直接解释为需要干预。

已验证：fixed8 相对 base 的四格 SR 差值均为正且 bootstrap 区间下界大于 0；相对普通 MPPI 的四格 SR 差值区间全部跨 0，未建立 fixed8 的独立优势。两个方形格普通 MPPI 的 SR 点估计均比 fixed8 高 1.4pp，但不能据此声称普通 MPPI 稳定更优。

未验证：新算法贡献。本轮没有取得方法级进展，仅完成所要求的 F 测量和强母体简单规划基线。
