### 15.2 主线（拟作第二篇方法论文）
- 方法：5 人圆形训练的价值网络 + 一步前瞻，部署时零训练；只在物理风险时刻（匀速外推 2 s 内净距 < 0.1 m）或低进展时调用冻结 MPPI，规划失败回退网络。
