## 14. 10-17 新结果（甲、乙'、丙、CC、Gemini）

### 14.0 本节共同条件（读数前必看）

- 评测：20 人，20S = 方形、20C = 圆形；固定用例 311000–311499，每格 500 例，各臂逐例配对；95% 区间是按 case 配对 bootstrap 10000 次（未做多重比较校正）。调参只用 310000–310199。
- 母体（"base"）：GRU T24 s443 rl_model_ep10000（只在 5 人圆形 5C 上训练，IL50 + RL10000），以及 KDA 强母体。base 20S：GRU 80.8/5.8/13.4，KDA 74.2/7.4/18.4（SR/CR/TO %）。
- 环境：CrowdNav，ORCA 行人；**robot.visible = false（行人看不见机器人，不对机器人做反应）**；TTC5，80 个候选动作，一步价值前瞻。
- 冻结 MPPI（下称 mpc）：16 步时域，256 样本，行人按**匀速外推**，终端项是**到目标距离的自由空间启发值，不是价值网络**；默认只在"低进展"时触发；首步保留原生 CV 安全掩码与平滑。
- 训练续训类实验（R0–R3）：都从 GRU base 继续训练 402000 环境步，单 seed，20 人圆形/方形混合。
- 跨设备：本地 3060（numpy 1.26.4）与 4090（numpy 1.24.4）有极少数终局差异（2000 例中 2 例：311277、311405），所以配对只在同一台机器的结果内部做。
